# hunt_repair2

Example world id for a large hunt/repair scene (export-shaped layout: `world.json` + `assets/`).

**Git:** Prefer not committing GLB binaries unless the team wants them in the repo; keep a local copy or use Git LFS if shared.

**Load:** File → Example Worlds, MCP `load_example_world` with `{ "exampleWorldId": "hunt_repair2" }`, or `npm run agent:work-on-project -- --example-world hunt_repair2`.
