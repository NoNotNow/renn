Code: `tools/hunt-profile-evo/` (genome.ts, fitness.ts, tasks.ts, pool.ts, worker.ts/worker-boot.mjs, store.ts, evolve.ts, run.ts, compare.ts, common.ts, evo.test.ts, seeds/{S8,P1,LMnoC}.json; B0 probes untouched under probe/ and imported).
Other changes: `src/test/avLab/lab.ts` repoRoot from `import.meta.url` (no behaviour change); `tools/hunt-maze/geometry.ts` + `scenarios.ts`: optional held-out start set (`buildSpecs(..., heldOut=true)`, default path unchanged).

## Design
- Genome: 33 keys (LMnoC 29 + cuspHeadW/cuspReachW/cuspLook/gearIncW), each with on/off flag + normalised value (bounds from AV_GENOME_SPEC, 4-sig-digit quantised) + hold (0.5..6 s, 0.25 grid). Absent key = inherit binding. Empty = base (hash `base`, no params). No CPU-budget keys (asserted).
- Search: (mu+lambda), pop = offspring per gen, binary tournament, uniform crossover (p 0.5), per-key toggle/gauss mutation, dedupe by profile hash. Gen 0 = seed gen: base, S8, P1, LMnoC (+ mutants if pop > 4). `--gens N` = total generations after gen 0.
- Candidate pipeline: sentinel tier (9 tasks, 5 cases) -> fail = infeasible, harness skipped (score = 500 + 200*violation + base fitness). Pass -> harness on full train set (63 episodes) -> if fitness <= elite cut (eliteCount-th best verified feasible of the population, or base fitness; fixed at gen start) the remaining proxy cases (22 cases, both budgets, 40 tasks incl. kr) run. Feasible = every proxy case passes. Else "unverified" (never elite-protected beyond ranking by fitness, never reported best; promoted later if it beats a later cut). Violation = sum over failing cases of margins worse than min(base slack, 0), normalised by max(|limit|,1), floor 0.1 per failing case.
- Fitness (min) = 0.5*solo + 1*flee + 1*flee-real of [mean exit w/ timeout + (30*unreached + 3*hits + 0.5*reversals + 0.2*reverseS + 0.05*contactFrames)/n] + 0.05*activeKeys. All overridable with `--weights JSON`.
- One worker_threads pool (<=5, hard cap) for harness episodes and proxy cases, one sim at a time per thread. Task cache `tasks.jsonl` (append) keyed profileHash+task, so no finished task is recomputed after a kill. `checkpoint.json` (atomic) after each candidate; offspring list fixed in the checkpoint before evaluation. SIGTERM/SIGINT flush + exit 143/130. Config signature mismatch on resume is refused.
- Seeds are decoded through quantisation (4 sig digits), so seed hashes differ trivially from raw files.
- Held-out: per maze, 3 other cells (>= 12 m from every train start, depth floor 0.3 vs 0.5, yaw role rotated by one) -> 21 starts; verified disjoint in evo.test.ts. Chaser placement derives from the new start.

Proxy results reproduce B0: P1 fails maze-gate-exit:full, mazemod-one-exit:full; LMnoC fails the 8 B0 rows; S8 and base pass. Example held-out signal (subset A,B start 1): LMnoC held-out flee 1/2 reached, 7 hits (overfits train), S8 equals base there.

## Cost estimate (full train set, 63 episodes, ~3.5x effective parallelism observed)
sentinel ~12 CPU-s, harness ~250 CPU-s, full proxy ~26 more CPU-s. If ~50% of offspring fail the sentinel: pop 12 ~1700 CPU-s = ~8 min/gen; if all pass: ~3300 CPU-s = ~16 min/gen. Pop 16: ~11-21 min/gen. The smoke showed a high sentinel-fail rate (6 of 8 offspring/mutants), so expect the lower end, with a low feasible rate early.
